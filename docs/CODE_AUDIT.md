# گزارش بازبینی کد

## دامنه‌ی بازبینی

تمام فایل‌های Python، checkpointهای موجود، CSVهای خروجی، README و یادداشت‌های معماری بررسی شدند. به دلیل نبود فایل خام دیتاست‌ها در آرشیو، استخراج کامل و بازآموزی مدل‌ها اجرا نشد. صحت نحوی، مسیرهای اصلی پردازش و forward مدل‌ها با آزمون‌های مصنوعی بررسی شد.

## اصلاحات اعمال‌شده

### پردازش سیگنال

- قرارداد علامت در تخمین تأخیر فازی اصلاح شد؛ مقدار مثبت اکنون در هر دو روش cross-correlation و phase به معنای عقب‌افتادن سیگنال دوم است.
- معیار شبه-coherence تک‌بینی که عملاً همواره نزدیک یک بود با magnitude-squared coherence واقعی جایگزین شد.
- ویژگی‌های fall time، area، duty ratio و upstroke slope به استخراج ویژگی موج افزوده شد.
- اصطلاحات PTT/PWV در کد دو-محلی به inter-site peripheral delay و apparent inter-site velocity تغییر یافت.

### داده و فشار خون

- `SessionBPDataset` شناسه‌ی فرد و جلسه را حفظ می‌کند و داده‌ی گمشده را پیش از تقسیم به‌طور سراسری پر نمی‌کند.
- آموزش فشار خون از تقسیم رکوردی به تقسیم آزمودنی‌محور train/validation/test تغییر یافت.
- imputation، استانداردسازی ویژگی و استانداردسازی هدف فقط با داده‌ی آموزش انجام می‌شود.
- مدل جمعیتی میانگین فشار خون به‌عنوان baseline غیرآموزشی اضافه شد.
- `BatchNorm` در `BPFeatureMLP` با `LayerNorm` جایگزین شد تا برای batchهای کوچک پایدارتر باشد.

### بازتولیدپذیری و بسته‌بندی

- نسخه‌ی موردنیاز Python به ۳.۱۰ یا جدیدتر اصلاح شد؛ کد از union type syntax جدید استفاده می‌کند.
- وابستگی‌های پروژه در `pyproject.toml` و `requirements.txt` تکمیل شدند.
- اسکریپت `audit_results.py` برای ساخت manifest از checkpointها و CSVها اضافه شد.
- پنج آزمون smoke/unit برای تأخیر، HR، morphology، مدل‌ها و پیش‌پردازش فشار خون اضافه شد.

## نتیجه‌ی آزمون

فرمان‌های زیر بدون خطا اجرا شدند:

```text
python -m compileall -q rppg_lab scripts tests
python -m unittest discover -s tests -v
```

هر پنج آزمون عبور کردند.

## محدودیت‌های باقی‌مانده

- نتیجه‌ی نهایی قفل‌شده برای مدل‌های HR وجود ندارد؛ checkpointها بر اساس validation انتخاب شده‌اند.
- strict cross-dataset model evaluation هنوز اجرا نشده است.
- `MultiROIWaveformNet` پیاده‌سازی شده اما نتیجه‌ی آموزش ثبت‌شده ندارد.
- هیچ داده یا نتیجه‌ی معتبر فشار خون در آرشیو موجود نیست.
- برای اطمینان از صحت کامل pipeline، پس از در دسترس قرار گرفتن دیتاست‌ها باید آزمون end-to-end و بازتولید جدول‌ها اجرا شود.
